## Process Builder Basics

*Legacy point-and-click automation (criteria → actions) — now superseded by Flow.*

### 🌱 Simple

*Beginner - plain language*

**Process Builder** is a legacy click automation tool: when a record is created/edited, check **criteria** and run **actions** (update fields, create records, send email, call flows). Salesforce now replaces it with **Flow**.

### 📏 Limits

*Governor & platform limits*

- Retired for new automation - use Flow.
- Shares the transaction's 100 SOQL / 150 DML / 10s CPU budget.
- Roughly 10x more expensive than a before-save Flow for same-record updates.
- Order relative to other automation is not guaranteed.
