## Dynamic Dashboard

*A dashboard that shows data 'as the logged-in user' rather than one fixed running user.*

### 🌱 Simple

*Beginner - plain language*

A **dynamic dashboard** shows each viewer *their own* data — it runs "as the logged-in user". So one dashboard serves everyone: each rep sees their numbers, each manager sees their team's, without separate copies.

### 📏 Limits

*Governor & platform limits*

- Edition-based count cap; no scheduling/subscription; runs as viewer (respects their sharing); not in private folders for others.

## Dashboard Filters

*Viewer-selectable filters that re-slice all components at once — one dashboard, many views.*

### 🌱 Simple

*Beginner - plain language*

**Dashboard filters** let viewers change what the whole dashboard shows — pick a Region, Product, or Date range and *every* component updates. One dashboard becomes many views without editing it.

### 📏 Limits

*Governor & platform limits*

- Few filters per dashboard; capped values; only affect components whose reports contain the field; don't change grouping.

## Dashboard Components

*The individual visuals (chart, gauge, metric, table) that make up a dashboard.*

### 🌱 Simple

*Beginner - plain language*

**Dashboard components** are the individual visuals on a dashboard — a bar chart, donut, gauge, metric number, or table. Each is powered by a **report** and shows one slice of the picture.

### 📏 Limits

*Governor & platform limits*

- Max components per dashboard; each needs a source report; grouping set by the report; refresh cost scales with components.
