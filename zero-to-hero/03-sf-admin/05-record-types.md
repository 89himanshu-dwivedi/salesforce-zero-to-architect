## Business Process

*Record-type-driven variations of a record's lifecycle (stages/statuses) for different teams.*

### 🌱 Simple

*Beginner - plain language*

A **Business Process** lets different **record types** use different sets of stages/statuses — e.g., a "New Business" sales process vs a "Renewal" process, each with its own Opportunity Stage values.

### 📏 Limits

*Governor & platform limits*

- Only on Opportunity/Case/Lead/Solution; process = subset of the master picklist; tied to record types.

## Picklist Assignment

*Record types control which picklist values are available — tailored choices per process/persona.*

### 🌱 Simple

*Beginner - plain language*

**Picklist assignment** via record types lets you show *different picklist values* for different record types. A "Retail" record type might offer different Industry/Type values than a "Healthcare" one — from the same master picklist.

### 📏 Limits

*Governor & platform limits*

- UI-scoping only (not API-enforced); per-record-type subset + default; global value sets for sharing; dependent picklists layer on.
