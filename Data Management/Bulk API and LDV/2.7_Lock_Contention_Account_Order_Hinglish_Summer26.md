## Lock Contention Kya Hai

Lock contention tab hota hai jab **do parallel batches ek hi parent record par lock chahte hain**.

```text
Batch 1 → Parent Account ko lock karna chahta hai
Batch 2 → Same Account ko lock karna chahta hai
              ↓
        Lock Competition
              ↓
        Lock Contention
```

Account–Order example se mechanism samjho.

## Use Case Setup — Account Aur Order Ka Relationship

**Poore section me yahi example use hoga.**

| Data Model | Meaning |
|---|---|
| **Account** | Parent record |
| **Lookup Relationship** | One-to-many relationship |
| **Orders** | High-volume child records |

```text
Account
   │
   ├── Order 1
   ├── Order 2
   ├── Order 3
   └── ...
```

### Normal / Success / Failure / Watch-out

**Normal step:** Account → Orders → multiple Orders load → parallel batches.

**Success:** Different Accounts → different parent locks → less competition → parallel processing → successful load.

**Failure:** Same Account → multiple parallel batches → same parent lock → lock contention → failures/retries → throughput down.

**Watch-out:** Sirf child records ko batches me split karna enough nahi hai; parent relationship bhi dekhna zaroori hai.
