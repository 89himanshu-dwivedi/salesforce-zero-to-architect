# 3.4.1 Solution 2 — Overall Architecture

Susannah ka solution intentionally simple hai:

```text
                    CLEAN BIKES
                         |

       +-----------------+-----------------+
       |                 |                 |

     SALES            SERVICE          EXPERIENCE

       v                 v                 v
    Leads             Cases           Customers

    Contracts         Rules
```

### Core Philosophy

> **"Jitna possible ho, standard Salesforce capabilities use karo; customisation sirf jahan business requirement genuinely demand kare."**

Ye architecture approach maintainability ke liye strong ho sakti hai.

# 3.4.3 Licensing Ka Nazariya

Original solution ka key difference:

> **Dealers ko full Sales Cloud diya — Nikki se yahi bada farak hai.**

| User Type | Original License | Original Reasoning |
|---|---|---|
| Customers | **Customer Community** | Volume bahut zyada hai aur Opportunities jaise sales objects ki need nahi |
| Channel Manager | **Sales Cloud** | Poora sales process |
| Customer Sales Rep (CSR) | **Sales Cloud + Cases** | Specialised Service Cloud license ki jagah Sales Cloud + Cases |
| Dealers | **Sales Cloud (full license)** | Shuru mein dealers ko "thoda internal" jaisa samjha |
