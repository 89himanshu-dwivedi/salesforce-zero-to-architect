# 3.3.2 Org Strategy Aur User Licenses

## Single Org — Sab Ek Jagah

Nikki ka approach:

> **Single org — sab ek jagah.**

Yani Sales, Service, Dealers aur Customers ke data/processes ko ek Salesforce org mein consolidate karna.

### Why Single Org?

Potential benefits:

- common customer/dealer data;
- common security model;
- common product catalog;
- common reporting;
- fewer cross-org integrations;
- common identity/data relationships;
- single platform governance.

### Architect Caveat

Single org automatically best nahi hota.

CTA mein justify karna hoga:

- data residency;
- regulatory boundaries;
- business-unit independence;
- security isolation;
- org limits;
- deployment model;
- integration complexity;
- operational ownership.
