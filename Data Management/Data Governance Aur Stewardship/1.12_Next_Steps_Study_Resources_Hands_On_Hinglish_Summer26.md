# Trailhead Playground Spin Up Karo

Apna khud ka **data quality scoring process** banao — object by object.

Example mental model:

```text
Account
 ├── Completeness
 ├── Accuracy
 ├── Consistency
 ├── Duplicate Risk
 └── Usage
        ↓
   Quality Score
```

Phir same idea ko different objects par apply karo:

```text
Account
Contact
Opportunity
Case
Custom Object
```

### Practice Goal

Sirf score calculate karna goal nahi hai.

Ye bhi socho:

- Score kisne define kiya?
- Kaun monitor karega?
- Threshold kya hai?
- Bad score par action kya hoga?
- Dashboard kisko dikhna chahiye?
- Data owner kaun hai?

Ye questions Data Architecture + Data Governance thinking develop karte hain.

# Dashboards Aur List Views Banao

Aise dashboards aur list views banao:

> **Taaki log apna dirty data spot kar sakein.**

Example:

```text
Data Quality Dashboard
        ↓
Bad / Missing / Duplicate Data
        ↓
Record Owner
        ↓
User fixes data
        ↓
Quality improves
```

Dashboard ka purpose sirf reporting nahi hai.

It should create:

```text
Visibility
   ↓
Awareness
   ↓
Action
   ↓
Improvement
```
