# 1.3 Governance Ko Salesforce Features Me Kaise Utaarein

Governance ke principles kaagaz par acche lagte hain.

Asli architect-level sawaal:

> **"In governance principles ko Salesforce mein implement kaise karoge?"**

Is session mein 4 major levers hain:

```text
1. Integration
2. Access Control
3. Duplicate Management
4. AppExchange / Data Quality Tools
```

Lekin modern Salesforce architecture mein inke saath:

- Permission Sets
- Permission Set Groups
- Sharing
- Validation
- Flow
- Data Loader
- Data Quality monitoring
- Data 360 governance

bhi relevant ho sakte hain.

---

# 1. Data Aata Kahan Se Hai?

## Initial Load, Users Aur Integrations

Salesforce sirf data **collect** nahi karta.

Salesforce:

```text
Data Receive
+
Data Store
+
Data Process
+
Data Share
+
Data Push
```

sab kar sakta hai.

Agar Salesforce ko customer-information repository bana rahe ho, to data generally multiple channels se aa sakta hai.

---

## 1️⃣ Initial Load

Initial implementation ke time existing transactional/legacy system se data Salesforce mein migrate ho sakta hai.

Example:

```text
Legacy CRM / ERP
      ↓
Extract
      ↓
Transform / Clean
      ↓
Validate
      ↓
Salesforce
```

### Governance Questions

Migration se pehle:

- Data owner kaun?
- Source of truth kaunsa?
- Duplicate strategy?
- Required fields?
- Data quality threshold?
- Historical data kitna migrate karna hai?
- Sensitive data?
- Retention requirement?

---

# 2️⃣ Users Take Over

Initial migration ke baad users Salesforce mein:

- Create
- Update
- Correct
- Enrich

data karte hain.

Yahin governance ka **ongoing operational** part start hota hai.

### Example

Sales user Account create karta hai.

Governance needs:

```text
Required fields
       ↓
Validation
       ↓
Duplicate check
       ↓
Access control
       ↓
Save
       ↓
Monitoring
```

---

# 3️⃣ Integrations Push Out

Salesforce se data downstream systems mein ja sakta hai.

Example:

```text
Salesforce
    ↓
Integration Layer
    ↓
ERP
    ↓
Invoicing
```

or:

```text
Salesforce
    ↓
Marketing Platform
```

or:

```text
Salesforce
    ↓
Data Platform / Analytics
```
