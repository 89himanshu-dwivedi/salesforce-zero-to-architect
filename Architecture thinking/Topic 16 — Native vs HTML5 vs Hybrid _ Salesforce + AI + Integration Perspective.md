# 16.1 Native App Kya Hai?

**Native = platform-specific application**

Platform ki supported language aur tooling use hoti hai.

### 🍎 iOS

```text
Swift / Objective-C
        +
Xcode
```

### 🤖 Android

```text
Kotlin / Java
        +
Android Studio
```

Salesforce Mobile SDK native iOS aur Android applications ko Salesforce Platform ke saath integrate karne ke liye support karta hai.

Do not ignore these limitations.
