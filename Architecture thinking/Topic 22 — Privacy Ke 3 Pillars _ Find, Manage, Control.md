# 🔐 Topic 22 — Privacy Ke 3 Pillars
## Find → Manage → Control

Practical privacy architecture ko 3 simple pillars me samajh sakte hain:

> **1. Find → Data kaha hai?**  
> **2. Manage → Data request ko kaise handle karenge?**  
> **3. Control → Customer ko kya control denge?**

Ye concept Salesforce + Integration + AI architecture me bahut important hai.

---

# 🧠 22.1 Teeno Pillars Ek Nazar Me

Order important hai.

```text id="7eq7dc"
1. FIND
   ↓
Data kaha hai?

2. MANAGE
   ↓
Data requests kaise fulfil karenge?

3. CONTROL
   ↓
Customer ko kya choice/control denge?
```

### Why This Order?

Agar aapko pata hi nahi:

**"Customer ka data kaha hai?"**

to aap effectively manage ya control nahi kar sakte.

# 🔍 Pillar 1 — FIND

## "Mera customer data kaha-kaha hai?"

Ye privacy program ka **foundation** hai.

Architect ko identify karna hai:

- Kya data hai?
- Kahan stored hai?
- Kis customer ka hai?
- Data owner kaun hai?
- System owner kaun hai?
- Kaun access karta hai?
- Kis purpose ke liye use hota hai?
- Kiske saath share hota hai?
- Kaunse external systems connected hain?

### 🔹 Salesforce Example
