# 18.1 Salesforce Kya Test Karta Hai?

Salesforce apne standard mobile product/platform ke bahut saare components ko test karta hai.

High-level areas include:

- UI testing
- Regression testing
- Unit-level testing
- Performance testing
- Security testing
- Accessibility
- Platform/server-side changes
- Localization
- Release/upgrades

### Lekin Important Point

Salesforce ne **platform/product** test kiya hai.

Do not ignore these limitations.
